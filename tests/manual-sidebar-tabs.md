# Manual Test Specification: Tabbed Sidebar Framework & Features

This document provides step-by-step manual test procedures for verifying the **Tabbed Sidebar Framework**, including top-toolbar tab navigation, multi-workspace switching, recent files stack, outline drag-and-drop reordering, Famous Marks quick filters, active windows detection, screen positioning, and the side drawer overlay.

---

## Test Datasets

Every test opens its sample file from the repository, so each run starts from the same content and there is nothing to type, save or delete.

**To open a file:** open the address under test followed by `?open=tests/<file>`, for example `https://app.famouskai.com/?open=tests/fixtures-outline-spec.md`. It opens in the app under its own name, unsaved. The file type decides which Famous Marks count (`docs/FAMOUS-MARK.md`, "Where a Mark Counts").
